# Guía: Recuperar Contraseña por SMS

## ¿Olvidaste tu contraseña?

Si has olvidado tu contraseña, sigue estos pasos para restablecerla con el teléfono registrado en tu usuario.

### Paso 1: Acceder a la opción de recuperación
1. Ve a la página de login.
2. Haz clic en **¿Olvidaste tu contraseña? Recupérala aquí**.

### Paso 2: Solicitar el código
1. Ingresa tu **nombre de usuario**.
2. Haz clic en **Enviar Código**.
3. Si la cuenta existe, está activa y tiene un teléfono registrado, recibirás un código de 6 dígitos por SMS.

### Paso 3: Verificar el código
1. Ingresa el código recibido por SMS.
2. El código es válido por **30 minutos**.
3. El sistema solo permite continuar si el código coincide con el registrado para tu teléfono.

### Paso 4: Crear una nueva contraseña
1. Ingresa una contraseña segura de al menos **8 caracteres**.
2. Confirma la contraseña.
3. Haz clic en **Restablecer Contraseña**.

### Paso 5: Iniciar sesión
1. Si el cambio fue exitoso, verás una confirmación.
2. Inicia sesión con tu usuario y la nueva contraseña.

---

## Problemas comunes

### "Código inválido o expirado"
- **Causa**: El código no coincide, ya fue usado o pasaron más de 30 minutos.
- **Solución**: Solicita un nuevo código desde la pantalla de recuperación.

### "Las contraseñas no coinciden"
- **Causa**: Los dos campos de contraseña son diferentes.
- **Solución**: Escribe exactamente la misma contraseña en ambos campos.

### "La contraseña debe tener al menos 8 caracteres"
- **Causa**: Tu contraseña es muy corta.
- **Solución**: Crea una contraseña con mínimo 8 caracteres.

### No recibí el SMS
- Verifica con el administrador que tu teléfono esté registrado correctamente.
- Solicita un nuevo código si el anterior expiró.
- Si persiste, el administrador debe revisar la configuración del proveedor SMS.

---

## Recomendaciones de seguridad

- No compartas el código SMS con nadie.
- El código solo debe usarse en la pantalla de recuperación de contraseña.
- Cierra sesión cuando termines de usar el sistema.
